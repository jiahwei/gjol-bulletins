四、秘境更新：

>>新增秘境观战功能 

现在玩家可以对好友列表中正在进行秘境挑战的玩家开启观战了，每个玩家同时最多只能被一名玩家观战。

在秘境观战时会自动跟随观战玩家，并可以发送位置标记和提醒表情，该信息只有观战者和被观战者双方可见。

玩家在秘境中被观战时会获得一个[被观战指导]效果（并显示在队伍面板中），效果描述中会显示正在观战玩家的名称，也可通过右键移除该效果来请离观战者。

系统设置-偏好中添加了“秘境和铭锋论剑中允许好友进行观战”的选项。

队伍设置中添加了“拒绝接受观战”的选项，勾选为拒绝会阻止所有队伍成员被观战并请离当前队伍中所有观战者。（匹配队伍不可调整该设置）

任务“祖祖祖爷爷的宝藏·二”调整为完成玉轮仙藏·太一独步的任务“遗华反质”之后可以接取，当前版本已完成的角色不受影响。

 

七、数值调整：

>> 集仙令更新

助战使等级调整为：最高等级560，同时集仙令进行对应替换。剑主奇谭中的集仙令·剑主等级提高为530，并且可以重新领取一次。

 

>> 符咒更新

1.新增“祝符”类道具，使用后可解锁对应部位、对应等级的符咒施加权限，该权限账号共享。

2.新装备施加符咒方式调整，通过祝符解锁对应符咒权限后，可在“装备成长-符咒”界面中，为装备施加对应符咒。

3.新增装备符咒方案，装备的符咒选择将保存至当前技能方案，切换技能方案后，会切换至对应符咒方案。

 

 >> 星蕴效果调整

星蕴【亢池】调整为提高会心治疗3%/6%/12%/18%/25%

星蕴【大火】和【舆鬼】调整为 星蕴【星聚】攻击招式仅命中一个目标时伤害提升3%

星蕴【积卒】调整为急速加成5%/10%/15%

 

 >> 血露薇调整

「血露薇悬赏·玉轮仙藏」中，针对任务完成后开启的宝箱，每个账号每日只能获得一次账号类型奖励。

 

 >> 镶嵌石调整

星罗璜·断·历世调整为打断成功后15秒内伤害提高15%，每60秒只能触发1次。

星罗璜·霰·历世调整为攻击招式命中多个目标时伤害提升5%

 

 >> 装备成长调整

1.装备可升级上限、可强化上限调整为角色数据。

2.调整对应上限提升的材料为角色消耗。

 

 >> 其他数值调整

4月7日更新后，由四海生金与寻仙探秘中获取的可交易的星罗璜由一级调整为二级。

4月7日更新后，盟会活跃度达到1000时的盟会活跃奖励·四中随机获取的日轮璜与月弦璜由一级调整为四级。

 

八、玩法调整：

>> 历世万法调整

1. 新增部分食材、食物、食谱等。

2. 「玉轮仙藏」场景中新增部分渔产，并在「四海生金·图录志」中追加了关联图鉴。

 

>> 记忆之匣调整

记忆之匣匹配区分为普通匹配和排行榜难度匹配。

 普通匹配对应的是该秘境的困难难度，无法登上记忆之匣排行榜。排行榜难度匹配对应的是该秘境的豪侠难度，可以登上记忆之匣排行榜。

记忆之匣榜单截止时间调整为每周四、周日零点。周四周日0~6点期间无法上榜。

版本更新后，记忆之匣排行榜将结算并发奖。

 

>> 济云万法调整

随着步云洲重建工程的进境，「济云万法」将在“明心九天”版本中追加新的重建内容。同时，未能完成全部“玉轮铃音”重建任务、开启全部对应济云匣的玩家仍可通过版本切换功能继续游玩相关内容、追求往期奖励。

1. “新品·明心”商店上架【天衣·次芳丛·袍】、【天衣·次芳丛·履】等商品。相应的兑换代币“济云印·明心”将在“明心九天”济云匣中产出。

2. “明心九天”济云匣中额外加入尘晶奖励。

3. 赈云册的周获取上限提升至15000。此外，开启「玉轮仙藏」场景各处的秘椟也将有机会获得赈云册。

4. “重建步云洲·玉轮铃音”排行榜将在版本开放后停止更新数据。与此同时，开放全新的“重建步云洲·明心九天”排行榜，此榜单会在下一个新版本来临之际停止更新数据。

5. 在乾坤袋中炼化灵材充裕、满足任务目标需求的情况下，灵材提交类任务将可以直接提交已炼化的灵材。

6. 修改原有“云舟笺·铃音”的图标，使之更贴合「玉轮铃音」版本的主视觉。
